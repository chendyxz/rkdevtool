## RKDevTool v0.14.0

**Release date:** 2026-09-01
**Full changelog:** https://github.com/hiifong/rkdevtool/compare/v0.13.0...v0.14.0

### Fixed
- **Modern Loader boot failure after upgrade:** Persist Loader IDBlocks instead of treating the Loader as a regular partition image. Loaders with `FlashHead` and legacy IDBlocks are both handled.
- **`FlashBoost` omission:** Some newer Rockchip Loaders require the `FlashBoost` ARM64 boot component. RKDevTool now writes every Loader that includes it in the required order: `FlashHead`, `FlashBoost`, `FlashData`, then `FlashBoot`.
- **Firmware `parameter` placement:** Write the packaged `parameter` payload at Rockchip's fixed LBA `0x2000` before partition images.
- **Android GPT parsing:** Respect the declared `PARM` payload length so unrelated trailing package data cannot be interpreted as partitions.

### Changed
- **Loader transition handling:** Wait briefly after the Maskrom Boot download before probing the temporary Loader interface, while keeping Loader readiness timeout at 30 seconds.

### Validation
- RK3566 and RK3576 firmware upgrade flows were validated with native Rust/RockUSB writes.
- Automated test suite: 57 tests passing.
