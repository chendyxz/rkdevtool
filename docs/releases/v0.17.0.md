## RKDevTool v0.17.0

**Release date:** 2026-09-24
**Full changelog:** https://github.com/chendyxz/rkdevtool/compare/v0.16.4...v0.17.0

### Highlights
- **OTA packaging:** a new page builds OTA update zips from an APK or a ROM OTA package. `version.json` and the payload are written with the store (no compression) method, byte-identical to packages produced by `zip -0`.
- **Device log viewer:** virtualized rendering plus a custom overlay scrollbar keep the log readable at thousands of lines, and Tag / PID filters now accept multiple values.

### Added
- **OTA packaging page** (`OTA 打包`) with APK / ROM tabs, version and PK fields, a live `version.json` preview, and progress reporting during packing.
- **`build_ota_zip` command** and a `cargo run --example ota_pack -- <apk|rom> <version> <pk> <payload> <out.zip>` entry point for verifying packages from the command line.
- **Multi-value log filters:** Tag and PID accept several values separated by spaces, commas, or `|`. Values match with OR inside a field and combine with AND across fields (level threshold and full-text search still apply).

### Improved
- **Log rendering performance:** the logcat view now renders only the visible window instead of every line, with a self-drawn scrollbar (overlay, 28 px minimum thumb, track paging) shared with the bottom log panel.
- **Firmware info parsing:** results are cached by `(path, mtime, size)` and parsed off the main thread, so switching pages no longer freezes the window and GB-scale firmware is not re-read on every visit.
- **Stale firmware paths:** when the selected firmware was deleted or moved, the parsed firmware / Loader / chip information is cleared and the path is reset once the file is confirmed missing; a given path is reported only once per session.
- **Logcat lifecycle:** the resident `adb logcat` child process is reaped on application exit, so restarting the app no longer leaves orphan `adb` processes streaming from the device.
- **Dark theme controls:** the app declares `color-scheme`, so native scrollbars and form controls follow the dark log surfaces instead of being drawn with light-theme colors.

### Validation
- Automated test suite: 76 library tests passing, including OTA zip layout compared against `zip -0` output and firmware info cache invalidation.
- Frontend: `vue-tsc --noEmit` and `vite build` complete without errors.
