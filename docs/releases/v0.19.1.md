## RKDevTool v0.19.1

**Release date:** 2026-09-28
**Full changelog:** https://github.com/chendyxz/rkdevtool/compare/v0.19.0...v0.19.1

### Highlights
- **The update prompt is now part of the app.** Replacing the native dialog means the release notes stay readable: the dialog opens with a few plain-text highlights, can expand to the complete notes in a scrollable panel, links out to the GitHub release, and keeps download progress and errors in the same window.
- **Progress you can actually watch.** Download percentage, byte counter and the install step are shown inside the dialog next to the buttons, instead of a modal that hides the window behind it.

### Added
- **In-app update dialog** (`UpdateDialog.vue`): version header, a highlights list, an optional "Show full notes" toggle, a GitHub release link, an inline error area, and a footer that stays pinned while the notes scroll.
- **Plain-text rendering of the full release notes** (`plainReleaseNotes()`): Markdown headings, bullets, bold labels and inline code are reduced to readable text, list markers become `•`, and paragraph spacing is collapsed so the whole note fits a scrollable box.
- **Update state shared across the app**: `useAppUpdater()` now keeps `prompt`, `errorText` and the download progress in module scope, so the sidebar's "Check for updates" button and the dialog read and drive the same state without prop plumbing.

### Improved
- **Update failures no longer open a second dialog.** A failed download or install reports the error inside the dialog and leaves *Update now* available for an immediate retry.
- **The dialog cannot be dismissed into a black hole.** While a download or install is running, the window's *Later* button and the overlay click are ignored so progress stays visible; the buttons re-enable as soon as it finishes.
- **Release notes with no highlights still show something:** when the digest is empty the dialog skips straight to the full plain-text notes, and the *Show full notes* toggle only appears when the digest actually omitted part of the notes.
- **Escape closes the update dialog** (and does not leak to the page behind it).

### Validation
- `npm run build` (including `vue-tsc --noEmit`) completes without warnings.
- `plainReleaseNotes()` was verified against a real release body: `docs/releases/v0.19.0.md` (Markdown, backticks, bold labels, `###` headings) reduces to 21 plain lines with no markup left behind, empty input returns an empty string, and the digest for that body is correctly flagged as truncated.
- The removal of the `update.notesMore` key was confirmed to have no remaining references in the frontend.
- macOS and Windows installers are built and published by the same workflow as v0.19.0.
