## RKDevTool v0.12.0

**Release date:** 2026-08-23
**Full changelog:** https://github.com/hiifong/rkdevtool/compare/v0.11.0...v0.12.0

### Highlights
- **RockUSB Download Image:** Loader download, partition-table writes, and forced address writes now use the Rust RockUSB backend. Normal image downloads no longer invoke `upgrade_tool` `UL` / `DI` / `WL` commands.
- **RockUSB firmware upgrade:** `update.img` is unpacked into a temporary directory, then its Loader and flashable partitions are written through RockUSB. Both common `MiniLoaderAll.bin` and `download.bin` Loader names are recognized.
- **Android firmware support:** Android GPT layouts, legacy Rockchip `parameter` layouts, sparse images, and `grow` partitions are resolved before partition writes.

### Improved
- **Loader handling:** wait for the device to become ready after Loader download; do not reset after a Loader-only operation; reset only after all requested non-Loader images have been written successfully.
- **Progress and logs:** display byte progress using B, KiB, MiB, or GiB as appropriate; keep in-place progress stable and preserve a horizontal log scrollbar for long output.
- **Advanced operations:** use English action identifiers internally while retaining localized UI labels. Flash/Chip/Capability reads, device tests, reset, Maskrom entry, storage switching, erase, and image export continue to use Rust/RockUSB.
- **Documentation:** refreshed the README with current screenshots for Download Image, Upgrade Firmware, and Advanced, plus an explicit Rust/RockUSB migration status.

### Compatibility
- The project is still migrating toward a pure Rust/RockUSB implementation.
- The remaining user-facing operations that use the official `upgrade_tool` are: device partition list (`PL`), clear serial (`SN`), detect secure mode (`RSM`), export serial log (`RCL`), and switch USB3 (`SSD`).

### Upgrade
- Install the v0.12.0 package from this release as a normal replacement upgrade.
- The bundled `upgrade_tool` is still required for the compatibility commands listed above. Prefer v2.44+ when those commands are needed on newer chips.
