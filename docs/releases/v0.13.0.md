## RKDevTool v0.13.0

**Release date:** 2026-08-29
**Full changelog:** https://github.com/hiifong/rkdevtool/compare/v0.12.0...v0.13.0

### Highlights
- **Windows Rockusb driver support:** device discovery and flashing on Windows now use the user-installed official Rockchip `Rockusb` driver. RKDevTool does not bundle or install the driver.
- **More reliable Loader transitions:** after a Maskrom Loader download, RKDevTool waits through USB re-enumeration and retries the active Rockusb interface before starting flash operations.

### Improved
- **Windows device detection:** determine Maskrom and Loader modes through the installed driver and show a concise device location in the status bar.
- **Windows setup documentation:** document the DriverAssistant installation requirement and the expected driver binding in Device Manager.
