## RKDevTool v0.15.0

**Release date:** 2026-09-13
**Full changelog:** https://github.com/hiifong/rkdevtool/compare/v0.14.0...v0.15.0

### Fixed
- **SPI NAND firmware upgrades:** Write modern Loader IDBlocks through RockUSB raw NAND sector operations, including the required per-page OOB data and ECC, rather than treating NAND as a linear block device.
- **Loader redundancy and verification:** Select valid physical blocks for Loader replicas, verify every written copy, and cap the replica count at the accessible raw-NAND window.
- **UBI partition upgrades:** Detect UBI images from their EC header and erase the target partition range before rewriting it. This removes stale physical eraseblocks without relying on hardcoded partition names.

### Improved
- **Upgrade diagnostics:** Report raw-NAND Loader placement, UBI pre-flash erasure, and validation failures with enough device context to diagnose a failed flash operation.

### Validation
- Automated Rust tests passed: 65 library tests, plus the RockUSB unit, integration, Maskrom, and documentation test suites.
